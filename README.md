# Single-cell workflows on Pennsieve

Pennsieve workflows for single-nucleus / single-cell RNA-seq and multiome data: **Single-nucleus Atlas Mapping & Condition Comparison** (sc-prep → sc-qc → sc-integrate → sc-annotate → {sc-markers, st-compare} → sc-report) and **Multiome Gene Regulation** (atac-prep → atac-regulome → sc-report).

- The apps, their ports and file formats: [docs/conventions.md](docs/conventions.md).
- Workflow definitions (the body of `POST /compute/workflows/definitions`): [workflow/](workflow/), generated by `scripts/build-workflows.py` from the apps' `app.yml` and release tags.
- Demo data from Pennsieve Discover: `scripts/fetch-sample-data.sh`.

## Citing

If you used Pennsieve to store, analyse, share or publish data reported in a publication, please cite:

> Goldblum Z, Xu Z, Shi H, Orzechowski P, Spence J, Davis KA, Litt B, Sinha N, Wagenaar J. *Pennsieve: A Collaborative Platform for Translational Neuroscience and Beyond.* Scientific Data 2025;12:1834. doi:[10.1038/s41597-025-06075-5](https://doi.org/10.1038/s41597-025-06075-5)

Please also cite the datasets you used (their DOIs) and the methods each app lists: every report gathers them from the steps that ran, and each app's README and `CITATION.cff` credit the tools and data it builds on.
